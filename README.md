# Kyle Kelley

E-commerce and operations at a race car chassis and parts manufacturer. I build practical tools to fix the problems I find, using Python, JavaScript and AI.

## Problems I've solved

**Weekly price and MAP audits took 10 hours**
Built a Python tool (Pandas, BeautifulSoup, Playwright) that checks competitor pricing and MAP compliance. The audit now takes about 15 minutes.

**Dealer discounts were losing money on some parts**
Rebuilt the wholesale price lists for two dealer tiers from real item and bill-of-materials costs, with a minimum-margin floor on every SKU (3,000+ SKUs per list).

**A holiday promotion that couldn't eat into margin**
Set up coupon rules so dealers can't stack the promo code on top of their dealer pricing, and excluded low-margin products. Added a one-click banner that copies the code and fills it in at checkout.

**Customers didn't know when orders would arrive**
Wrote cart and checkout badges that show whether each item ships from our stock (with a live same-day shipping cutoff countdown), ships direct from the manufacturer, or is built to order.

**Shipping was undercharged on older products**
Audited the shipping rate setup and found retired box sizes still in use and about 1,200 products with no dimensions, the cause of dimensional-weight undercharges.

**Parts left bins with no record**
Launched a QR code system: technicians scan the bin, enter the quantity taken, and can flag a low or empty bin, so inventory counts and reorders stay accurate.

**Manual order entry and catalog cleanup**
Connected the online store to QuickBooks so orders flow automatically. Cleaned up a catalog of about 4,000 SKUs (titles, metadata, part numbers, redirects).
